3 · Zwei Wege zum Fine-Tune

Ansatz A (empfohlen): ControlNet trainieren
  • U-Net SDXL bleibt eingefroren.
  • Das ControlNet (Kopie des Encoders) wird auf Paaren Skizze → Ziel weitertrainiert.
  • Diffusers-Skript: train_controlnet_sdxl.py (laut README gesehen, Skript nicht geöffnet).
  • Braucht viel GPU-Speicher, laut Doku grob ≥ 24 GB für SDXL (unverifiziert).
Ansatz B (billiger): LoRA auf dem U-Net
  • ControlNet bleibt eingefroren, nur kleine Adapter werden trainiert.
  • Rang r klein halten (z. B. 8–32, Annahme); Anzahl trainierbarer Parameter ein Bruchteil des U-Nets.
  • Ergebnis ist eine kleine Datei, die auf das Basismodell aufgesetzt wird.
LoRA-Prinzip
W′ = W₀ + (α / r) · B · A W₀ ∈ ℝd×k eingefroren (SDXL-Gewicht) A ∈ ℝr×k trainiert, Start: zufällig B ∈ ℝd×r trainiert, Start: 0 → Anfangs wirkt der Adapter nicht r ≪ min(d, k) Trainingsparameter: r·(d+k) statt d·k

Ein Adapter kann pro Kategorie (Tiere, Pflanzen, Fabelwesen) getrennt gespeichert und bei Bedarf geladen werden, ohne das Basismodell zu kopieren.
